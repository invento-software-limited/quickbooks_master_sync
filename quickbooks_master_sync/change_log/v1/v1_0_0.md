## QuickBooks Master Sync v1.0.0 Release Notes

### Added
- QuickBooks Online OAuth2 authentication flow
- Chart of Accounts synchronization from QuickBooks to ERPNext
- Customer synchronization (QuickBooks Customers → ERPNext Customers)
- Supplier/Vendor synchronization (QuickBooks Vendors → ERPNext Suppliers)
- Item and Service synchronization (QuickBooks Items → ERPNext Items)
- Tax Rate and Tax Code synchronization
- Payment Terms synchronization
- Payment Methods synchronization
- QuickBooks Sync Dashboard with analytics charts and number cards
- Real-time sync progress dialog with step-by-step status updates
- Opening Balances sync at end of master data sync cycle
- QuickBooks Debug Log Viewer for inspecting API activity
- Customer & Supplier balance reconciliation
- Support for multi-company QuickBooks configurations
